Database self test

Runs the real create / read / update / delete round trip against the live Supabase project, using the same anon key and the same endpoints the quote tool and the designer use. Test rows are written under a ZZ-SELFTEST- prefix and deleted at the end, so nothing touches real customer data.

If a check fails, the HTTP status and the database's own error message are shown against it — that is what is needed to fix it. A failure here is a real failure: nothing on this page is stubbed.
