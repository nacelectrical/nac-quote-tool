Production setup

Everything that has to be proved against the live system, in one run. It writes only its own test rows and deletes them, and it stops to show you exactly what the customer/job migration would do before writing anything.

Before you press it

Run designer/production-setup.sql in the Supabase SQL editor first. That is the one thing this page cannot do for you — Supabase has no way to run SQL from a browser session. If you have not run it, press the button anyway: the results will tell you precisely what is missing.
